## Provenance & integrity

- Every side-by-side cell is the transcript's exact assistant output,
  **HTML-escaped for rendering only** — nothing rewritten, summarized, trimmed,
  or reordered.
- Regenerate any arm **byte-exact** (no escaping) with the bundled helper
  (`agent_tools/transcript_tokens.py`, inside the skill-evaluator skill dir):
  ```bash
  python agent_tools/transcript_tokens.py --grep "<that arm's RUN MARKER>" --full-text
  ```
- Arm labels (WITH / WITHOUT) were assigned by the orchestrator's private
  marker→arm map **after** the blind judging; the judge never saw the labels, the
  markers, or the token numbers.
- If an arm can't be recovered from the transcript, it's marked `unmeasured` here
  and in the report rather than fabricated.

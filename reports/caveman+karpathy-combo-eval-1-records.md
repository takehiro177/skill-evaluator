The original code runs in O(n²) because `item not in result` scans the entire `result` list on every iteration. Tracking seen items in a `set` makes membership checks O(1) average, bringing the total to O(n) while preserving first-seen order.

```python
def dedupe(items):
    seen = set()
    result = []
    for item in items:
        if item not in seen:
            seen.add(item)
            result.append(item)
    return result
```

If every item is guaranteed hashable and you don't mind the (small) difference in handling, Python 3.7+ also lets you do this in one line, since dicts preserve insertion order:

```python
def dedupe(items):
    return list(dict.fromkeys(items))
```

Note: both versions require items to be hashable. If the list can contain unhashable items (e.g. lists/dicts), the set-based approach won't work and you'd have to fall back to the original O(n²) scan — but for the common case of hashable elements, this is the right fix.

<pre>
A reusable retry helper. It retries on exception up to a fixed number of attempts, waits between tries, supports exponential backoff, and lets you restrict which exception types should trigger a retry. A decorator version is included for convenience.

```python
import time
import functools


def retry(
    func,
    *args,
    attempts=3,
    delay=0.5,
    backoff=1.0,
    exceptions=(Exception,),
    on_retry=None,
    **kwargs,
):
    """Call ``func(*args, **kwargs)``, retrying if it raises.

    Parameters
    ----------
    func : callable
        The function to call.
    attempts : int
        Maximum number of attempts (must be &gt;= 1).
    delay : float
        Initial delay in seconds between attempts.
    backoff : float
        Multiplier applied to the delay after each failed attempt
        (1.0 = constant delay, 2.0 = double each time).
    exceptions : tuple[type[BaseException], ...]
        Exception types that should trigger a retry. Anything else
        propagates immediately.
    on_retry : callable, optional
        Called as ``on_retry(exc, attempt)`` after each failed attempt
        that will be retried (useful for logging).

    Returns
    -------
    The return value of ``func`` on the first successful call.

    Raises
    ------
    The last exception raised by ``func`` if all attempts fail.
    """
    if attempts &lt; 1:
        raise ValueError("attempts must be at least 1")

    current_delay = delay
    last_exc = None
    for attempt in range(1, attempts + 1):
        try:
            return func(*args, **kwargs)
        except exceptions as exc:
            last_exc = exc
            if attempt == attempts:
                break  # out of retries; re-raise below
            if on_retry is not None:
                on_retry(exc, attempt)
            time.sleep(current_delay)
            current_delay *= backoff
    raise last_exc


def with_retry(attempts=3, delay=0.5, backoff=1.0, exceptions=(Exception,), on_retry=None):
    """Decorator form of :func:`retry`."""
    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            return retry(
                func, *args,
                attempts=attempts, delay=delay, backoff=backoff,
                exceptions=exceptions, on_retry=on_retry,
                **kwargs,
            )
        return wrapper
    return decorator
```

Usage examples:

```python
# Direct call
data = retry(fetch_url, "https://example.com", attempts=5, delay=1.0, backoff=2.0,
             exceptions=(ConnectionError, TimeoutError))

# As a decorator
@with_retry(attempts=4, delay=0.2, exceptions=(IOError,))
def read_config(path):
    ...
```

Notes:
- Constant delay by default (`backoff=1.0`); set `backoff=2.0` for exponential backoff.
- Only the exception types in `exceptions` trigger retries; everything else propagates immediately so you don't accidentally swallow programming errors.
- Re-raises the last exception (preserving its traceback) once attempts are exhausted, rather than masking the failure.
- `functools.wraps` keeps the decorated function's name and docstring intact.
</pre>

```python
import time
import functools


def retry(func, *args, attempts=3, delay=0.5, backoff=1.0,
          exceptions=(Exception,), **kwargs):
    """Call func(*args, **kwargs), retry on exception.

    attempts: max total tries (&gt;=1)
    delay: seconds before first retry
    backoff: multiplier applied to delay each retry (1.0 = constant)
    exceptions: tuple of exception types that trigger retry
    """
    if attempts &lt; 1:
        raise ValueError("attempts must be &gt;= 1")
    wait = delay
    last_exc = None
    for n in range(attempts):
        try:
            return func(*args, **kwargs)
        except exceptions as exc:
            last_exc = exc
            if n == attempts - 1:
                break
            time.sleep(wait)
            wait *= backoff
    raise last_exc
```

Decorator form:

```python
def retryable(attempts=3, delay=0.5, backoff=1.0, exceptions=(Exception,)):
    def deco(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            return retry(func, *args, attempts=attempts, delay=delay,
                         backoff=backoff, exceptions=exceptions, **kwargs)
        return wrapper
    return deco
```

Usage:

```python
data = retry(fetch_url, "http://x", attempts=5, delay=1, backoff=2,
             exceptions=(ConnectionError,))

@retryable(attempts=4, delay=0.2, exceptions=(IOError,))
def read_thing(path):
    ...
```

Notes:
- Last attempt does not sleep — fails fast.
- `backoff` gives exponential delay; default 1.0 = constant.
- Narrow `exceptions` in real use — catching bare `Exception` hides bugs.
- For production add jitter (`wait + random.uniform(0, wait)`) to avoid thundering herd.
</pre>

<pre>
A minimal retry helper. It calls `func`, and on any exception retries up to `attempts` times with a fixed `delay`, re-raising the last exception if all attempts fail.

```python
import time

def retry(func, attempts=3, delay=0.5, exceptions=(Exception,)):
    """Call func() and retry on failure.

    attempts:   total number of tries (must be &gt;= 1)
    delay:      seconds to wait between attempts
    exceptions: tuple of exception types that trigger a retry
    """
    if attempts &lt; 1:
        raise ValueError("attempts must be at least 1")
    last_exc = None
    for attempt in range(attempts):
        try:
            return func()
        except exceptions as exc:
            last_exc = exc
            if attempt &lt; attempts - 1:
                time.sleep(delay)
    raise last_exc
```

Usage:

```python
result = retry(lambda: do_request(url), attempts=5, delay=1.0)
```

Notes:
- Returns the result as soon as a call succeeds; re-raises the last exception after exhausting attempts.
- `exceptions` lets callers narrow what counts as retryable (e.g., `exceptions=(ConnectionError,)`); it defaults to `Exception`. This is the one small piece of configurability I included because "when it raises an exception" implies the caller may care which ones — drop it if you always want to retry on everything.
- No delay is added after the final failed attempt.
- Backoff/jitter were not requested, so I kept a fixed delay. If needed, change the sleep to `delay * (2 ** attempt)` for exponential backoff.
